# AI_skills

Инструменты и промпты, которые передаются **сессиям и машинам**: их можно взять
и применить, не пересказывая контекст проекта.

## Что здесь

| | |
|---|---|
| [`podgotovka-korpusa/`](podgotovka-korpusa_all/podgotovka-korpusa) | **скилл:** папка документов Word → файл фрагментов для векторной базы. Распознаёт скриншоты интерфейса, режет по структуре документа, закрепляет номера, вычищает персональные данные, проверяет результат |
| [`ПРОМПТ — развернуть на новой машине`](podgotovka-korpusa_all/ПРОМПТ%20—%20развернуть%20на%20новой%20машине.md) | для сессии, которая ставит инструмент на чистую машину: что прочитать, как поставить, три проверочных прогона и чего не делать |
| [`ПРОМПТ — панель оператора, пять экранов`](podgotovka-korpusa_all/ПРОМПТ%20—%20панель%20оператора,%20пять%20экранов.md) | для сессии, которая делает интерфейс сопровождения: пять экранов и вопрос, на который каждый отвечает |
| [`ЧИТАТЬ ПЕРВЫМ`](podgotovka-korpusa_all/ЧИТАТЬ%20ПЕРВЫМ%20—%20что%20здесь%20лежит.md) | оглавление: что здесь, что осталось снаружи и почему |

## Откуда это

Из рабочего проекта базы знаний по 1С:ERP и 1С:Документообороту. Через конвейер
прошли **169 документов, 2 478 фрагментов, 362 распознанных экрана**, поэтому
правила в нём не придуманы заранее, а выведены из поломок — и у каждого есть
цена в числах.

## Быстрый старт

```bash
pip install python-docx requests
cd podgotovka-korpusa_all/podgotovka-korpusa
cp config/корпус.yaml.образец config/мой.yaml      # прописать пути
cp config/ключи.env.образец   config/ключи.env     # вписать ключ
python prepare_corpus.py --config config/мой.yaml --stage registry
```

Полное описание — `podgotovka-korpusa/ЧИТАТЬ ПЕРВЫМ` и `SKILL.md`.

## Чего в репозитории нет намеренно

**Ключей.** Только образцы с пустым значением.

**Рабочих данных** (`work/`): разобранные экраны, реестр и — главное —
закреплённые номера документов. Таблица номеров привязывает «этот документ =
DOC-20» навсегда; принесённая в чужой проект, она раздаст новым документам
чужие номера.

**Эталонов регрессии** (`tests/fixtures/`): это были настоящие документы
компании, часть со скриншотами, где напечатаны персональные данные. Скрипт
регрессии в комплекте и сам скажет, чего ему не хватает; как завести свои —
в «ЧИТАТЬ ПЕРВЫМ».
